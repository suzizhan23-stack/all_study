## 一、有理数

### 1.1 正数与负数

| 概念 | 说明 | 示例 |
|------|------|------|
| 正数 | 大于0的数，前面可带"+"号 | `+5`, `3`, `1.2` |
| 负数 | 小于0的数，前面带"−"号 | `−3`, `−1.5`, `−2/3` |
| 0 | 既不是正数也不是负数 | `0` |

**相反意义的量**：收入与支出、上升与下降、向东与向西等。

### 1.3 相反数与绝对值

**相反数**：只有符号不同的两个数，如 `5` 和 `−5`。0的相反数是0。

$$
a \text{ 的相反数是 } -a
$$

**绝对值**：数轴上表示数a的点到原点的距离，记作 $|a|$。

$$
|a| = \begin{cases}
a & (a > 0) \\
0 & (a = 0) \\
-a & (a < 0)
\end{cases}
$$

> **记忆口诀**："正数的绝对值是它本身，负数的绝对值是它的相反数，0的绝对值是0。"

### 1.4 有理数的运算

| 运算 | 法则 | 示例 |
|------|------|------|
| 加法 | 同号取相同符号，绝对值相加；异号取绝对值大的符号，绝对值相减 | `(−3)+(−5)=−8`, `(−3)+5=2` |
| 减法 | 减去一个数等于加上它的相反数 | `3−(−2)=3+2=5` |
| 乘法 | 同号得正，异号得负，绝对值相乘 | `(−2)×(−3)=6`, `(−2)×3=−6` |
| 除法 | 除以一个数等于乘以它的倒数 | `(−6)÷(−2)=−6×(−1/2)=3` |

**运算律**：
- 交换律：$a+b = b+a$, $ab = ba$
- 结合律：$(a+b)+c = a+(b+c)$, $(ab)c = a(bc)$
- 分配律：$a(b+c) = ab+ac$

## 二、实数

### 2.1 平方根与立方根

| 概念 | 定义 | 示例 |
|------|------|------|
| 平方根 | 若 $x^2 = a$，则 $x$ 是 $a$ 的平方根 | $\pm\sqrt{9} = \pm3$ |
| 算术平方根 | 正数 $a$ 的正平方根，记作 $\sqrt{a}$ | $\sqrt{9}=3$ |
| 立方根 | 若 $x^3 = a$，则 $x$ 是 $a$ 的立方根 | $\sqrt[3]{8}=2$, $\sqrt[3]{-8}=-2$ |

> **易错**：$\sqrt{16} = 4$（算术平方根），而非 $\pm4$。

### 2.2 实数分类

```
            ┌─── 整数 ────┐
            │  正整数：1,2,3,…  │
    ┌── 有理数 ─┼  0            │
    │         │  负整数：−1,−2,… │
    │         ├── 分数 ────┤
实数 ┼──        │  正分数         │
    │         │  负分数         │
    │         └──────────┘
    └── 无理数：π, √2, √3, 0.1010010001…
```

> **无理数**：无限不循环小数。常见类型：π 类、$\sqrt{}$ 开不尽的、构造型。

## 三、代数式

### 3.1 整式

**单项式**：数字与字母的积，如 $3x^2y$（系数3，次数3）。

**多项式**：几个单项式的和，如 $x^2 + 2x + 1$（二次三项式）。

**同类项**：所含字母相同且相同字母指数也相同的项。

**整式加减**：去括号 → 合并同类项。

### 3.2 乘法公式（非常重要！）

| 公式 | 展开 |
|------|------|
| 平方差 | $(a+b)(a-b) = a^2 - b^2$ |
| 完全平方和 | $(a+b)^2 = a^2 + 2ab + b^2$ |
| 完全平方差 | $(a-b)^2 = a^2 - 2ab + b^2$ |

### 3.3 因式分解

> **定义**：把一个多项式化成几个整式的积的形式。

**方法**：
1. **提公因式法**：$ma+mb+mc = m(a+b+c)$
2. **公式法**：平方差、完全平方
3. **十字相乘法**：$x^2 + (p+q)x + pq = (x+p)(x+q)$

### 3.4 分式

> 形如 $\dfrac{A}{B}$（$B$ 含字母，$B \neq 0$）。

**性质**：$\dfrac{A}{B} = \dfrac{A \times C}{B \times C}$（$C \neq 0$）

**运算**：
- 加减：先通分，再加減
- 乘除：$\dfrac{A}{B} \cdot \dfrac{C}{D} = \dfrac{AC}{BD}$，$\dfrac{A}{B} \div \dfrac{C}{D} = \dfrac{A}{B} \cdot \dfrac{D}{C}$

### 3.5 二次根式

> 形如 $\sqrt{a} \;(a \geq 0)$。

**性质**：
- $(\sqrt{a})^2 = a \;(a \geq 0)$
- $\sqrt{a^2} = |a|$
- $\sqrt{ab} = \sqrt{a} \cdot \sqrt{b} \;(a \geq 0, b \geq 0)$
- $\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}} \;(a \geq 0, b > 0)$

## 四、方程与方程组

### 4.1 一元一次方程

> 标准形式：$ax + b = 0 \;(a \neq 0)$

**解法步骤**：去分母 → 去括号 → 移项 → 合并同类项 → 系数化为1。

### 4.2 二元一次方程组

> 标准形式：$\begin{cases} a_1x + b_1y = c_1 \\ a_2x + b_2y = c_2 \end{cases}$

**解法**：
- **代入消元法**：将一个方程变形，代入另一个方程
- **加减消元法**：方程两边分别相加或相减消去一个未知数

### 4.3 一元二次方程

> 标准形式：$ax^2 + bx + c = 0 \;(a \neq 0)$

**解法**（四种）：
1. **直接开平方法**：$x^2 = p \Rightarrow x = \pm\sqrt{p}$
2. **配方法**：$x^2 + bx \Rightarrow (x + \frac{b}{2})^2 - (\frac{b}{2})^2$
3. **公式法**（万能）：

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

4. **因式分解法**：化为 $(x - x_1)(x - x_2) = 0$

**判别式**：$\Delta = b^2 - 4ac$

| $\Delta$ | 根的情况 |
|----------|----------|
| $\Delta > 0$ | 两个不相等的实数根 |
| $\Delta = 0$ | 两个相等的实数根 |
| $\Delta < 0$ | 没有实数根 |

**根与系数的关系**（韦达定理）：

$$
x_1 + x_2 = -\frac{b}{a}, \quad x_1 x_2 = \frac{c}{a}
$$

### 4.4 不等式与不等式组

**不等式性质**：
1. $a > b \Rightarrow a \pm c > b \pm c$
2. $a > b, c > 0 \Rightarrow ac > bc$
3. $a > b, c < 0 \Rightarrow ac < bc$ ⚠️ **乘除负数要变号**

| 交点式 | $y = a(x - x_1)(x - x_2)$ | 已知与x轴交点 |

**顶点坐标**：
$$
h = -\frac{b}{2a}, \quad k = \frac{4ac - b^2}{4a}
$$

**对称轴**：$x = -\dfrac{b}{2a}$

**性质总结**：

| $a$ | 开口 | 顶点 | 最值 |
|-----|------|------|------|
| $a > 0$ | 向上 | 最低点 | 最小值 $= k$ |
| $a < 0$ | 向下 | 最高点 | 最大值 $= k$ |

### 7.2 三角形的重要线段

> 推论：直径所对的圆周角是直角（$90^\circ$）。

### 9.2 直线与圆的位置关系

| 位置 | 交点数 | 距离关系 |
|------|--------|----------|
| 相离 | 0 | $d > r$ |
| 相切 | 1 | $d = r$ |
| 相交（割线） | 2 | $d < r$ |

**切线性质**：切线垂直于过切点的半径。
**切线判定**：过半径外端且垂直于半径的直线是圆的切线。

### 9.3 圆中计算

$$
\text{弧长公式}：l = \frac{n\pi r}{180} \quad
\text{扇形面积}：S = \frac{n\pi r^2}{360} = \frac{1}{2} lr
$$

## 十、统计

### 10.1 基本概念

| 概念 | 定义 |
|------|------|
| **总体** | 考察对象的全体 |
| **样本** | 从总体中抽取的一部分个体 |
| **平均数** | $\bar{x} = \dfrac{x_1 + x_2 + \cdots + x_n}{n}$ |
| **中位数** | 将数据排序后，中间位置的数（偶数个时取中间两数平均值） |
| **众数** | 出现次数最多的数据 |
| **方差** | $s^2 = \dfrac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$ |
| **标准差** | $\sqrt{s^2}$ |

> **方差越小，数据越稳定**！

### 10.2 常见统计图

| 类型 | 用途 |
|------|------|
| 条形图 | 比较各类数据的大小 |
| 扇形图 | 体现各部分占总体的百分比 |
| 折线图 | 反映数据的变化趋势 |
| 直方图 | 展示数据的分布情况（连续分组） |

## 十一、概率

### 11.1 基本概念

- **必然事件**：概率 = 1
- **不可能事件**：概率 = 0
- **随机事件**：概率在 0 到 1 之间

$$
P(A) = \frac{\text{事件A包含的结果数}}{\text{所有等可能结果总数}}
$$

### 11.2 列举法

**列表法**：两步试验，结果不多时使用。

**树状图法**：三步及以上试验，清晰展示所有路径。
