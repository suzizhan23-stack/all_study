## 一、集合

### 1.1 集合的基本概念

| 概念 | 说明 | 示例 |
|------|------|------|
| 集合 | 确定的、互异的对象组成的整体 | $\{1,2,3\}$ |
| 元素 | 集合中的每个对象 | $1\in\{1,2,3\}$ |
| 空集 $\varnothing$ | 不含任何元素 | $\varnothing$ |
| 有限集 | 元素个数有限的集合 | $\{a,b,c\}$ |
| 无限集 | 元素个数无限的集合 | $\mathbb{N},\mathbb{Z},\mathbb{R}$ |

**常用数集**：
- $\mathbb{N}$ — 自然数集 $\{0,1,2,\dots\}$
- $\mathbb{N}^*$ 或 $\mathbb{N}_+$ — 正整数集 $\{1,2,3,\dots\}$
- $\mathbb{Z}$ — 整数集
- $\mathbb{Q}$ — 有理数集
- $\mathbb{R}$ — 实数集
- $\mathbb{C}$ — 复数集

### 1.2 集合间的关系

| 关系 | 记法 | 含义 |
|------|------|------|
| 子集 | $A \subseteq B$ | $A$ 中每个元素都在 $B$ 中 |
| 真子集 | $A \subsetneqq B$ | $A \subseteq B$ 且 $A \neq B$ |
| 相等 | $A = B$ | $A \subseteq B$ 且 $B \subseteq A$ |

> **结论**：含 $n$ 个元素的集合，子集数 $=2^n$，真子集数 $=2^n-1$。

| 运算 | 定义 | 性质 |
|------|------|------|
| 并集 $A \cup B$ | $\{x \mid x \in A \text{ 或 } x \in B\}$ | $A \cup A = A$，$A \cup \varnothing = A$ |
| 交集 $A \cap B$ | $\{x \mid x \in A \text{ 且 } x \in B\}$ | $A \cap A = A$，$A \cap \varnothing = \varnothing$ |
| 补集 $\complement_U A$ | $\{x \mid x \in U \text{ 且 } x \notin A\}$ | $A \cup \complement_U A = U$，$A \cap \complement_U A = \varnothing$ |
| 差集 $A \setminus B$ | $\{x \mid x \in A \text{ 且 } x \notin B\}$ | — |

**德摩根定律**（重要）：
$$
\complement_U(A \cup B) = \complement_U A \cap \complement_U B, \quad
\complement_U(A \cap B) = \complement_U A \cup \complement_U B
$$

### 1.4 区间表示法

| 不等式 | 区间 |
|--------|------|
| $a \leq x \leq b$ | $[a,b]$ |
| $a < x < b$ | $(a,b)$ |
| $x \geq a$ | $[a,+\infty)$ |
| $x < b$ | $(-\infty,b)$ |
| $\mathbb{R}$ | $(-\infty,+\infty)$ |

## 二、常用逻辑用语

### 2.1 充分条件与必要条件

| 关系 | 逻辑表述 | 符号 |
|------|----------|------|
| 充分不必要 | $p$ 能推出 $q$，$q$ 不能推出 $p$ | $p \Rightarrow q$ 但 $q \not\Rightarrow p$ |
| 必要不充分 | $p$ 不能推出 $q$，$q$ 能推出 $p$ | $p \not\Rightarrow q$ 但 $q \Rightarrow p$ |
| 充要条件 | $p$ 与 $q$ 等价 | $p \Leftrightarrow q$ |
| 既不充分也不必要 | 互相推不出 | $p \not\Rightarrow q$ 且 $q \not\Rightarrow p$ |

### 2.2 量词与命题否定

| 类型 | 原命题 | 否定 |
|------|--------|------|
| 全称量词 | $\forall x \in M, p(x)$ | $\exists x \in M, \lnot p(x)$ |
| 存在量词 | $\exists x \in M, p(x)$ | $\forall x \in M, \lnot p(x)$ |

> **记忆口诀**：全称变存在，存在变全称，结论加否定。

## 三、不等式

### 3.1 不等式性质

| 性质 | 公式 |
|------|------|
| 对称性 | $a > b \iff b < a$ |
| 传递性 | $a > b, b > c \Rightarrow a > c$ |
| 加法 | $a > b \Rightarrow a + c > b + c$ |
| 乘法（正） | $a > b, c > 0 \Rightarrow ac > bc$ |
| 乘法（负）⚠️ | $a > b, c < 0 \Rightarrow ac < bc$ |
| 同向可加 | $a > b, c > d \Rightarrow a + c > b + d$ |
| 倒数 | $a > b > 0 \Rightarrow \frac{1}{a} < \frac{1}{b}$ |

### 3.2 一元二次不等式

> 标准形式：$ax^2 + bx + c > 0 \;(a \neq 0)$

**解法**：先求根 → 再结合二次函数图像确定范围。

| $\Delta$ | $a > 0$时 $ax^2+bx+c > 0$ 的解集 |
|----------|----------------------------------|
| $\Delta > 0$（两根 $x_1 < x_2$） | $(-\infty, x_1) \cup (x_2, +\infty)$ |
| $\Delta = 0$（重根 $x_0$） | $(-\infty, x_0) \cup (x_0, +\infty)$ |
| $\Delta < 0$ | $\mathbb{R}$ |

> $a < 0$ 时两边同乘 $-1$ 化为 $a > 0$ 再解。

### 3.3 基本不等式（均值不等式）

> **核心公式**：$\sqrt{ab} \leq \dfrac{a+b}{2}$（$a,b > 0$），当 $a=b$ 时取等。

**记忆口诀**："一正二定三相等"：
1. $a,b$ 必须为正数（一正）
2. 和或积为定值（二定）
3. 等号成立条件 $a=b$（三相等）

**三大形式**：

$$
\frac{a+b}{2} \geq \sqrt{ab} \geq \frac{2}{\frac{1}{a}+\frac{1}{b}}
$$

$$
a^2 + b^2 \geq 2ab
$$

$$
\frac{b}{a} + \frac{a}{b} \geq 2 \;(a,b>0)
$$

### 3.4 穿根法（数轴标根法）

解高次不等式 $f(x) > 0$ 的步骤：
1. 将 $f(x)$ 分解因式，求出全部根
2. 在数轴上标根（从右上方开始）
3. **奇穿偶不穿**（奇次根穿过，偶次根反弹）
4. 上方为 $>0$，下方为 $<0$

## 四、函数的概念与性质

### 4.1 函数三要素

- **定义域**：自变量 $x$ 的取值范围
- **对应关系**：$f$（映射规则）
- **值域**：函数值的集合 $\{f(x) \mid x \in \text{定义域}\}$

> **判断同一函数**：定义域和对应关系完全一致。

### 4.2 函数的性质——单调性

| 定义 | 符号语言 |
|------|----------|
| 增函数 | $\forall x_1 < x_2$，有 $f(x_1) < f(x_2)$ |
| 减函数 | $\forall x_1 < x_2$，有 $f(x_1) > f(x_2)$ |

**判断方法**：
- 定义法：设 $x_1 < x_2$，作差 $f(x_1)-f(x_2)$ 判断符号
- 导数法：$f'(x) > 0$ 则增，$f'(x) < 0$ 则减

### 4.3 函数的性质——奇偶性

| 类型 | 条件 | 图像特征 |
|------|------|----------|
| 奇函数 | $f(-x) = -f(x)$ | 关于原点对称 |
| 偶函数 | $f(-x) = f(x)$ | 关于 $y$ 轴对称 |

> 定义域必须关于原点对称。既奇又偶：$f(x)=0$。

### 4.4 函数的性质——周期性

> 若存在非零常数 $T$ 使 $f(x+T) = f(x)$，则 $T$ 为周期。

**常见周期**：
- $f(x+a) = -f(x)$ ⇒ 周期 $T=2a$
- $f(x+a) = \dfrac{1}{f(x)}$ ⇒ 周期 $T=2a$
- $f(x+a) = f(x-a)$ ⇒ 周期 $T=2a$
- 三角函数：$\sin x, \cos x$ 周期 $2\pi$；$\tan x$ 周期 $\pi$

**运算性质**：
- $\log_a(MN) = \log_a M + \log_a N$
- $\log_a\dfrac{M}{N} = \log_a M - \log_a N$
- $\log_a M^n = n \log_a M$
- $\log_a \sqrt[n]{M} = \dfrac{1}{n} \log_a M$

**换底公式**（重要）：

$$
\log_a b = \frac{\log_c b}{\log_c a} \quad (a,c > 0, a,c \neq 1)
$$

> **常用推论**：$\log_a b \cdot \log_b a = 1$，$\log_{a^n} b^m = \dfrac{m}{n} \log_a b$

### 5.4 指数函数与对数函数的关系

> $y = a^x$ 与 $y = \log_a x$ 互为**反函数**，图像关于直线 $y = x$ 对称。

### 5.5 函数图像变换（重要）

| 变换 | 法则 | 示例 |
|------|------|------|
| 平移 | $f(x) \to f(x \pm a)$ 左加右减 | $f(x+1)$ 向左平移1 |
| 平移 | $f(x) \to f(x) \pm b$ 上加下减 | $f(x)+2$ 向上平移2 |
| 对称 | $f(x) \to f(-x)$ 关于y轴对称 | |
| 对称 | $f(x) \to -f(x)$ 关于x轴对称 | |
| 对称 | $f(x) \to -f(-x)$ 关于原点对称 | |
| 翻折 | $f(x) \to f(\|x\|)$ 保留右、对称左 | |
| 翻折 | $f(x) \to \|f(x)\|$ 下翻上 | |

### 5.6 函数的零点

> 使 $f(x)=0$ 的 $x$ 称为函数的零点。

**零点存在性定理**：若 $f(x)$ 在 $[a,b]$ 上连续且 $f(a)\cdot f(b) < 0$，则 $(a,b)$ 内至少有一个零点。

## 十三、等比数列

> **定义**：从第2项起，每一项与前一项的比等于同一个常数 $q$（$q \neq 0$）。

$$
a_n = a_1 q^{n-1}
$$

**前 $n$ 项和**（分类讨论）：

$$
S_n =
\begin{cases}
na_1, & q = 1 \\[4pt]
\dfrac{a_1(1-q^n)}{1-q}, & q \neq 1
\end{cases}
$$

**等比中项**：$a, G, b$ 成等比数列 $\iff G^2 = ab$。

**性质**：
- 若 $m+n = p+q$，则 $a_m \cdot a_n = a_p \cdot a_q$
- 若 $\{a_n\}$ 是等比数列，$\{S_n\}$ 在 $q\neq -1$ 时不一定是等比

## 十四、数列求和方法

| 方法 | 适用场景 | 示例 |
|------|----------|------|
| **公式法** | 等差/等比数列 | 直接套公式 |
| **裂项相消** | $a_n = \dfrac{1}{n(n+1)}$ 型 | $\dfrac{1}{n} - \dfrac{1}{n+1}$ |
| **错位相减** | 等差×等比（$\{n\cdot q^n\}$） | 通项为多项式×等比 |
| **分组求和** | 两类数列交替 | 等差+等比组合 |
| **倒序相加** | 对称特征的数列 | $C_n^0 + C_n^1 + \cdots + C_n^n$ |

**裂项常用公式**：

$$
\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}, \quad
\frac{1}{n(n+k)} = \frac{1}{k}\left(\frac{1}{n} - \frac{1}{n+k}\right)
$$

## 十六、平面向量

### 16.1 向量的基本概念

| 概念 | 说明 |
|------|------|
| 向量 | 既有大小又有方向的量，记作 $\vec{a}$ 或 $\overrightarrow{AB}$ |
| 模 | 向量的大小，$|\vec{a}|$ |
| 零向量 | 模为0，方向任意，$\vec{0}$ |
| 单位向量 | 模为1，$\vec{e}$ |
| 相等向量 | 方向相同、大小相等 |
| 共线向量 | 方向相同或相反的**非零向量** |
| 相反向量 | 方向相反、大小相等 |

### 16.2 向量运算

**加法**（平行四边形法则 / 三角形法则）：

$$
\vec{a} + \vec{b} = (x_1+x_2, y_1+y_2)
$$

**减法**：

$$
\vec{a} - \vec{b} = (x_1-x_2, y_1-y_2)
$$

**数乘**：

$$
\lambda\vec{a} = (\lambda x, \lambda y)
$$

> $\lambda > 0$ 同向，$\lambda < 0$ 反向，$|\lambda|$ 控制长度。

### 16.3 向量的数量积（点乘）

> $\vec{a} \cdot \vec{b} = |\vec{a}|\,|\vec{b}|\,\cos\theta$（$\theta$ 为夹角）

**坐标形式**：$\vec{a} \cdot \vec{b} = x_1x_2 + y_1y_2$

**重要公式**：
- 垂直：$\vec{a} \perp \vec{b} \iff \vec{a} \cdot \vec{b} = 0 \iff x_1x_2 + y_1y_2 = 0$
- 平行：$\vec{a} \parallel \vec{b} \iff \vec{a} = \lambda\vec{b} \iff x_1y_2 - x_2y_1 = 0$
- 夹角：$\cos\theta = \dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}|\,|\vec{b}|}$
- 投影：$\vec{a}$ 在 $\vec{b}$ 上的投影 $= |\vec{a}|\cos\theta = \dfrac{\vec{a}\cdot\vec{b}}{|\vec{b}|}$

### 16.4 三角形中的向量结论

- $\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CA} = \vec{0}$
- 重心 $G$：$\overrightarrow{GA} + \overrightarrow{GB} + \overrightarrow{GC} = \vec{0}$，$G\big(\frac{x_A+x_B+x_C}{3}, \frac{y_A+y_B+y_C}{3}\big)$
- **中点公式**：$M\big(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\big)$
- **定比分点**：$P$ 分 $\overrightarrow{P_1P_2}$ 比为 $\lambda$，则 $P\big(\frac{x_1+\lambda x_2}{1+\lambda}, \frac{y_1+\lambda y_2}{1+\lambda}\big)$

## 十八、空间几何体

### 18.1 常见几何体

| 几何体 | 表面积 | 体积 |
|--------|--------|------|
| 棱柱 | $S_{\text{侧}} + 2S_{\text{底}}$ | $V = Sh$ |
| 棱锥 | $S_{\text{侧}} + S_{\text{底}}$ | $V = \frac{1}{3}Sh$ |
| 圆柱 | $2\pi r^2 + 2\pi rh$ | $V = \pi r^2 h$ |
| 圆锥 | $\pi r^2 + \pi rl$（$l$ 母线） | $V = \frac{1}{3}\pi r^2 h$ |
| 圆台 | $\pi(r^2+R^2+rl+Rl)$ | $V = \frac{1}{3}\pi h(r^2+R^2+rR)$ |
| 球 | $4\pi R^2$ | $V = \frac{4}{3}\pi R^3$ |

### 18.2 点线面的位置关系

**四个公理**：
1. 不共线三点确定一个平面
2. 若一条直线上的两点在平面内，则直线在平面内
3. 两个不重合的平面有一个公共点，则有一条过该点的公共直线
4. 过直线外一点有且只有一条直线与该直线平行

**线面平行**的判定与性质：
- 判定：$a \not\subset \alpha$，$b \subset \alpha$，$a \parallel b$ ⇒ $a \parallel \alpha$
- 性质：$a \parallel \alpha$，$a \subset \beta$，$\alpha \cap \beta = b$ ⇒ $a \parallel b$

**面面平行**的判定：
- $a,b \subset \alpha$，$a \cap b = P$，$a \parallel \beta$，$b \parallel \beta$ ⇒ $\alpha \parallel \beta$

**线面垂直**的判定：
- $l \perp a$，$l \perp b$，$a,b \subset \alpha$，$a \cap b = P$ ⇒ $l \perp \alpha$

**三垂线定理**：平面内的一条直线，如果和平面的一条斜线的射影垂直，那么它也和这条斜线垂直。

### 18.3 空间向量与立体几何

> 用法向量解决空间中的角度和距离问题。

**线面角**：
$$
\sin\theta = |\cos\langle\vec{v}, \vec{n}\rangle| = \frac{|\vec{v} \cdot \vec{n}|}{|\vec{v}|\,|\vec{n}|}
$$

**二面角**：
$$
\cos\theta = \frac{\vec{n}_1 \cdot \vec{n}_2}{|\vec{n}_1|\,|\vec{n}_2|}
$$

> 二面角需根据实际情况判断锐角还是钝角。

**点到平面的距离**：
$$
d = \frac{|\overrightarrow{AP} \cdot \vec{n}|}{|\vec{n}|}
$$

## 十九、直线与圆

### 19.1 直线方程

| 形式 | 方程 | 适用 |
|------|------|------|
| 点斜式 | $y - y_0 = k(x - x_0)$ | 已知点和斜率 |
| 斜截式 | $y = kx + b$ | 已知斜率和截距 |
| 两点式 | $\dfrac{y-y_1}{y_2-y_1} = \dfrac{x-x_1}{x_2-x_1}$ | 已知两点 |
| 截距式 | $\dfrac{x}{a} + \dfrac{y}{b} = 1$ | 已知两截距 |
| 一般式 | $Ax + By + C = 0$（$A,B$ 不全为0） | 通用形式 |

**斜率**：$k = \tan\alpha = \dfrac{y_2-y_1}{x_2-x_1}$

**点到直线的距离**：
$$
d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}
$$

**平行线间的距离**：
$$
d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}
$$

**位置关系**：

| 关系 | $y=kx+b$ 形式 | $Ax+By+C=0$ 形式 |
|------|--------------|-------------------|
| 平行 | $k_1 = k_2$，$b_1 \neq b_2$ | $\dfrac{A_1}{A_2} = \dfrac{B_1}{B_2} \neq \dfrac{C_1}{C_2}$ |
| 垂直 | $k_1 k_2 = -1$ | $A_1A_2 + B_1B_2 = 0$ |
| 重合 | $k_1 = k_2$，$b_1 = b_2$ | $\dfrac{A_1}{A_2} = \dfrac{B_1}{B_2} = \dfrac{C_1}{C_2}$ |

### 19.2 圆的方程

**标准式**：$(x - a)^2 + (y - b)^2 = r^2$，圆心 $C(a,b)$，半径 $r$

**一般式**：$x^2 + y^2 + Dx + Ey + F = 0$
- 圆心 $(-\dfrac{D}{2}, -\dfrac{E}{2})$，半径 $r = \dfrac{1}{2}\sqrt{D^2+E^2-4F}$
- 需满足 $D^2+E^2-4F > 0$

**直线与圆的位置关系**（比较 $d$ 与 $r$）：
- $d > r$：相离
- $d = r$：相切
- $d < r$：相交（弦长 $= 2\sqrt{r^2 - d^2}$）

# 第九篇：计数原理与概率

---

## 二十一、计数原理

### 21.1 两大计数原理

| 原理 | 关键词 | 公式 |
|------|--------|------|
| 分类加法计数 | "或"（类类独立） | $N = m_1 + m_2 + \cdots + m_n$ |
| 分步乘法计数 | "且"（步步关联） | $N = m_1 \times m_2 \times \cdots \times m_n$ |

### 21.2 排列

> 从 $n$ 个不同元素中取出 $m$ 个（$m \leq n$）**按顺序排成一列**。

$$A_n^m = n(n-1)(n-2)\cdots(n-m+1) = \frac{n!}{(n-m)!}$$

**全排列**：$A_n^n = n!$

### 21.3 组合

> 从 $n$ 个不同元素中取出 $m$ 个（$m \leq n$）**组成一组（不计顺序）**。

$$C_n^m = \frac{A_n^m}{m!} = \frac{n!}{m!(n-m)!}$$

**性质**：
- $C_n^m = C_n^{n-m}$
- $C_n^m + C_n^{m-1} = C_{n+1}^m$

### 21.4 二项式定理

$$(a+b)^n = C_n^0 a^n + C_n^1 a^{n-1}b + C_n^2 a^{n-2}b^2 + \cdots + C_n^n b^n$$

**通项公式**（第 $r+1$ 项）：
$$T_{r+1} = C_n^r a^{n-r}b^r$$

**二项式系数性质**：
- 对称性：$C_n^r = C_n^{n-r}$
- 最大值：$n$ 为偶数时 $C_n^{\frac{n}{2}}$ 最大；$n$ 为奇数时 $C_n^{\frac{n-1}{2}} = C_n^{\frac{n+1}{2}}$ 最大
- 系数和：$C_n^0 + C_n^1 + \cdots + C_n^n = 2^n$
- 奇数项系数和 = 偶数项系数和 = $2^{n-1}$

## 二十二、概率

### 22.1 古典概型

$$P(A) = \frac{\text{事件A包含的基本事件数}}{\text{基本事件总数}}$$

### 22.2 条件概率

$$P(B|A) = \frac{P(AB)}{P(A)}$$

### 22.3 全概率公式

$$
P(B) = \sum_{i=1}^n P(A_i) \cdot P(B|A_i)
$$

> 其中 $\{A_i\}$ 是样本空间的一个完备划分。

### 22.4 相互独立事件

$$P(AB) = P(A) \cdot P(B)$$

## 二十三、随机变量及其分布

### 23.1 离散型随机变量

**分布列**：$P(X = x_i) = p_i$，满足 $\sum p_i = 1$

**期望**：
$$E(X) = \sum_{i=1}^n x_i p_i$$

**方差**：
$$D(X) = \sum_{i=1}^n (x_i - E(X))^2 p_i = E(X^2) - (E(X))^2$$

### 23.2 二项分布

> $n$ 次独立重复试验，每次成功概率 $p$。

$$X \sim B(n, p)$$

$$P(X=k) = C_n^k p^k (1-p)^{n-k}$$

$$E(X) = np, \quad D(X) = np(1-p)$$

### 23.3 超几何分布

> 从 $N$ 件产品中（含 $M$ 件次品）任取 $n$ 件，次品数 $X$。

$$P(X=k) = \frac{C_M^k C_{N-M}^{n-k}}{C_N^n}$$

$$E(X) = n\frac{M}{N}$$

### 23.4 正态分布

> $X \sim N(\mu, \sigma^2)$

- 曲线关于 $x=\mu$ 对称
- $\sigma$ 决定"胖瘦"，$\sigma$ 越小越集中

**3σ 原则**：
- $P(\mu-\sigma \leq X \leq \mu+\sigma) \approx 68.3\%$
- $P(\mu-2\sigma \leq X \leq \mu+2\sigma) \approx 95.4\%$
- $P(\mu-3\sigma \leq X \leq \mu+3\sigma) \approx 99.7\%$

## 二十四、统计基础

### 24.1 抽样方法

| 方法 | 适用场景 | 特点 |
|------|----------|------|
| 简单随机抽样 | 总体较少 | 抽签法或随机数表 |
| 分层抽样 | 有明显差异的层 | 各层按比例抽取 |
| 系统抽样 | 总体无规律 | 等距抽样 |

### 24.2 用样本估计总体

**频率分布直方图**：
- 纵轴 = 频率/组距（**不是频率本身**）
- 所有小矩形面积之和 = 1

**百分位数**：$p$ 百分位数表示约 $p\%$ 的数据小于或等于该值。

**数字特征**：

| 特征 | 公式 | 意义 |
|------|------|------|
| 平均数 | $\bar{x} = \frac{1}{n}\sum x_i$ | 数据集中趋势 |
| 方差 | $s^2 = \frac{1}{n}\sum(x_i-\bar{x})^2$ | 数据波动大小 |
| 标准差 | $s = \sqrt{s^2}$ | 方差的开方 |

### 24.3 相关性与回归

**相关系数 $r$**：
$$
r = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sqrt{\sum(x_i-\bar{x})^2\sum(y_i-\bar{y})^2}}
$$

| $r$ | 相关程度 |
|-----|----------|
| $r > 0$ | 正相关 |
| $r < 0$ | 负相关 |
| $|r|$ 越接近1 | 线性相关越强 |
| $|r|$ 越接近0 | 线性相关越弱 |

**线性回归方程**：$\hat{y} = bx + a$

$$
b = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2}, \quad a = \bar{y} - b\bar{x}
$$

### 24.4 独立性检验

> 判断两个分类变量是否独立。

$2\times2$ 列联表 → 计算卡方统计量：

$$\chi^2 = \frac{n(ad-bc)^2}{(a+b)(c+d)(a+c)(b+d)}$$

> 查表判断。通常 $\chi^2 > 3.841$ 有 $95\%$ 把握认为有关。

## 二十五、导数的概念

### 25.1 导数的定义

f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}

### 25.2 基本求导公式

| $f(x)$ | $f'(x)$ |
|--------|---------|
| $C$（常数） | $0$ |
| $x^n$ | $n x^{n-1}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x$ |
| $a^x$ | $a^x \ln a$ |
| $e^x$ | $e^x$ |
| $\log_a x$ | $\dfrac{1}{x \ln a}$ |
| $\ln x$ | $\dfrac{1}{x}$ |

### 25.3 求导法则

**四则运算**：
- $(u \pm v)' = u' \pm v'$
- $(uv)' = u'v + uv'$（乘积法则）
- $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$（商法则）

**链式法则（复合函数求导）**：
> 若 $y = f(g(x))$，则 $y' = f'(g(x)) \cdot g'(x)$

$$
\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}
$$

## 二十六、导数的应用

### 26.1 函数的单调性

> 在区间 $(a,b)$ 内：
> - $f'(x) > 0$ ⇒ $f(x)$ 单调递增
> - $f'(x) < 0$ ⇒ $f(x)$ 单调递减
> - $f'(x) = 0$ ⇒ 可能是极值点

### 26.2 极值与最值

**极值判定**（一阶导数）：
1. 求 $f'(x) = 0$ 的根（驻点）
2. 驻点左正右负 → 极大值点；左负右正 → 极小值点
3. 若 $f'(x)$ 不改变符号 → 不是极值点

**极值判定**（二阶导数）：
- $f'(x_0) = 0$ 且 $f''(x_0) < 0$ ⇒ 极大值
- $f'(x_0) = 0$ 且 $f''(x_0) > 0$ ⇒ 极小值

**最值求解**：
1. 求 $(a,b)$ 内所有极值点
2. 计算所有极值点及端点 $f(a), f(b)$ 的函数值
3. 最大者为最大值，最小者为最小值

### 26.3 切线方程

> 曲线 $y=f(x)$ 在点 $(x_0, f(x_0))$ 处的切线方程：

$$y - f(x_0) = f'(x_0)(x - x_0)$$

### 26.4 恒成立问题

> 常用方法：分离参数 → 构造函数 → 求最值

- $f(x) \geq 0$ 恒成立 $\iff f(x)_{\min} \geq 0$
- $f(x) \leq a$ 恒成立 $\iff f(x)_{\max} \leq a$

### 26.5 利用导数证明不等式

> 构造辅助函数 $F(x) = f(x) - g(x)$，证明 $F(x) \geq 0$。

**常见不等式**（需掌握）：
- $e^x \geq x + 1$（当 $x=0$ 取等）
- $\ln x \leq x - 1$（当 $x=1$ 取等）
- $\sin x < x < \tan x$（$x \in (0, \frac{\pi}{2})$）
