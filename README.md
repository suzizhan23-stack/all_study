证明（目标）：对 ArrayStack，执行任意 m 次 add(i,x) 和 remove(i)，总时间复杂度是：O(m)，因此平均每次：O(1)

1、执行了：m 次操作。
2、发生了：r 次 resize。
3、定义：ni 表示：第 i 次 resize 时数组里元素数量。


前提：resize 时，数组已满，要复制全部元素(n个)，之后大小变成2n
所以：第 i 次 resize：
    成本(resize成本，既复制操作)：T_i = O(n_i)

所以得到总成本（总成本表达出来了，分析与m的关系）：xx

观察分析：
    扩容规则：满了->容量×2
    当前 resize 时：n_i
    上次 resize 时：n_i/2
    也就是说，第i次与第i-1次 resize 间隔了 n_i/2 次操作。
    那么得出，一直到当前 resize ，总的至少执行了 xx 次操作，才会触发这一次的 resize
    又因为前提 执行了 m 次操作，因此得出不等式

代回总式
    此时将不等式代入上面总成本，得到 T(resize总成本) 与 m 关系

上面总成本是resize的复制成本，再加上普通操作的成本
